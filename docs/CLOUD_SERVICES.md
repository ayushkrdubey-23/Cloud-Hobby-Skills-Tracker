# Cloud Services

## Firebase Authentication
Used for registration, login, identity, and authenticated sessions.

## Cloud Firestore
Used as the cloud NoSQL document database for profiles, skills, practice, goals, milestones, posts, and comments.

## Firebase Storage
Used for profile and community post image files.

## Firebase Security Rules
Used for authentication-based access control and user ownership checks.

## GitHub
Used for source-code version control, documentation, and project portfolio proof.

## Cloud Computing Concepts Demonstrated

| Concept | Project Usage |
|---|---|
| SaaS | Web application accessed through a browser |
| PaaS | Firebase managed application services |
| Cloud Database | Cloud Firestore |
| Object Storage | Firebase Storage |
| Authentication | Firebase Authentication |
| Authorization | Firestore security rules |
| Serverless | Firebase managed backend services |
| Scalability | Managed cloud services reduce server-management requirements |
| Client-Server | React communicates with cloud services |
| Version Control | Git/GitHub |
