# Project Overview

## Project Name
**Cloud Hobby & Skills Tracker**

## Purpose
A cloud-based platform where users track hobbies and skills, record practice activities, create goals, monitor milestones, and share progress.

## Problem
Learning a hobby or skill often involves separate notes, spreadsheets, or applications. This makes it difficult to maintain a single history of progress and share achievements.

## Solution
The application combines personal skill tracking and community sharing in one cloud-based web application.

## Main User Flow

```text
Register/Login
      ↓
Create Profile
      ↓
Add Skills
      ↓
Record Practice
      ↓
Create Goals
      ↓
Track Milestones
      ↓
View Dashboard
      ↓
Share Progress in Community
```

## MVP Scope
- Authentication
- Profile
- Skills
- Practice
- Goals
- Milestones
- Dashboard
- Community posts
- Likes
- Comments
- Image uploads
- Firestore authorization

## Future Scope
Advanced social features, notifications, analytics, REST APIs, automated testing, CI/CD, and production-scale infrastructure can be added later.
